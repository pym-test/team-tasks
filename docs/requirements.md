# requirements

## 기능 요건 (MVP)

| ID | 이름 | 설명 | 우선순위 |
|----|------|------|---------|
| FR-01 | 일감 생성 | 제목·설명·담당자·우선순위·마감일을 입력해 새 일감을 칸반 보드에 추가한다. 모든 팀원이 생성할 수 있으며 역할 제한 없음. | 높음 |
| FR-02 | 일감 수정 | 기존 일감의 모든 필드(제목·설명·담당자·우선순위·마감일)를 다이얼로그에서 수정하고 저장한다. | 높음 |
| FR-03 | 상태 변경 | 일감을 할 일 → 진행 중 → 완료 세 단계 사이에서 변경한다. 변경 즉시 카드가 해당 컬럼으로 이동하고 헤더 요약 수치가 갱신된다. 누구나 변경 가능. | 높음 |
| FR-04 | 담당자·키워드 필터 | 담당자 드롭다운과 키워드 검색창을 조합해 보드를 실시간으로 좁힌다. 선택 해제 시 전체 일감이 복원된다. | 높음 |
| FR-05 | 일감 삭제 | confirm 다이얼로그 승인 후 일감을 영구 삭제한다. 누구나 삭제할 수 있으며 취소 시 아무 변경 없음. | 중간 |

## 비기능 요건

### 성능

| # | 지표 | 목표치 |
|---|------|--------|
| P-01 | 초기 페이지 로드(로컬 네트워크 기준) | 2 초 이내 |
| P-02 | 일감 생성·수정·삭제·상태 변경 응답 | 200 ms 이내 |

### 보안

| # | 지표 | 목표치 |
|---|------|--------|
| S-01 | XSS 방지 | 사용자 입력값을 DOM에 직접 삽입하는 코드 0건 (React 기본 이스케이프 유지) |
| S-02 | 민감 정보 저장 금지 | localStorage에 비밀번호·토큰 등 인증 정보를 저장하는 필드 0개 |

### 가용성

| # | 지표 | 목표치 |
|---|------|--------|
| A-01 | 오프라인(인트라넷) 동작률 | 외부 네트워크 없이 100% 기능 정상 동작 |
| A-02 | 데이터 영속성 | 브라우저 재시작 후 localStorage 데이터 100% 유지 |

| # | 지표 | 목표치 |
|---|------|--------|
